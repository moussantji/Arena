Importer dans Figma

Trois étapes, aucun plugin

  1. Télécharger DIALLO-Indigo-Minuit.sketch avec le bouton ci-dessus.
  2. Dans Figma : menu File → Import… — ou glisser le fichier directement sur le canvas.
  3. Le fichier s’ouvre avec ses deux pages : 01 · Écrans et 02 · Design system.
Pourquoi .sketch et pas .fig — le .fig est un format binaire propriétaire qui ne peut être écrit que par Figma lui-même. .sketch est le format pivot ouvert, importé nativement par Figma : même résultat, sans passer par l’API.
